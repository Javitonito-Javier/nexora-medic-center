# 🏥 Nexora Labs Medic Center
> **Gestión Clínica Inteligente - Multi-Tenant Ready**

Sistema ERP/CRM especializado para clínicas médicas y farmacias, desarrollado por **Nexora Labs**. 
Esta versión incluye arquitectura **Multi-Cliente**, permitiendo desplegar instancias personalizadas para diferentes centros médicos bajo una misma base de código.

## 🚀 Características Principales
- **Core Nexora**: Motor de reglas médicas, inventario FEFO y facturación SAR.
- **Personalizable**: Cambia logos, colores y nombres sin tocar el código.
- **Seguro**: Encriptación de datos, roles granulares y auditoría completa.
- **Offline-First**: Funciona sin internet y sincroniza automáticamente.

## 🛠️ Instalación Rápida
1. Clona este repositorio.
2. Copia `.env.example` a `.env`.
3. Ejecuta `docker compose up -d`.
